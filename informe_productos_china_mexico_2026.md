4. **Lámpara LED de corazón para auto** - Baja competencia, viral

### ⚠️ CONSIDERACIONES IMPORTANTES:

**Certificaciones necesarias para México:**
- NOM (Norma Oficial Mexicana) para productos eléctricos
- COFEPRIS para productos de belleza/skincare
- Etiquetado en español obligatorio

**Costos adicionales a considerar:**
- Flete marítimo/aéreo: $3-8 USD/kg
- Aranceles: 0-15% según producto (T-MEC favorable)
- IVA: 16%
- Agente aduanal: $200-500 USD
