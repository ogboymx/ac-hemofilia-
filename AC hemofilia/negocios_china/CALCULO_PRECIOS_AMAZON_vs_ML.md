# 🎯 ANÁLISIS Y RECOMENDACIONES

## ¿Cuándo conviene Amazon?

### ✅ VENTAJAS DE AMAZON:
1. **Menor comisión base** (15% vs 13-20.5% de ML)
2. **Tarifa mínima baja** ($10 vs $25-$37 de ML)
3. **FBA Prime** = más ventas (clientes pagan más por Prime)
4. **12 meses gratis** de suscripción
5. **Audiencia de mayor poder adquisitivo**
6. **Menos competencia** que en Mercado Libre (para ciertos productos)

### ❌ DESVENTAJAS DE AMAZON:
1. **FBA es caro** para productos pesados o grandes
2. **Curva de aprendizaje** más empinada
3. **Requiere códigos UPC/EAN** ($500-$2,000 MXN)
4. **Menos tráfico** que Mercado Libre en México
5. **Políticas más estrictas** de devolución

## ¿Cuándo conviene Mercado Libre?

### ✅ VENTAJAS DE ML:
1. **Mayor audiencia** en México (líder indiscutible)
2. **Mercado Envíos Full** más barato que FBA
3. **Más flexible** con nuevos vendedores
4. **Sin requerimientos** de códigos de barras
5. **Mejor para packs** (elimina costo fijo a $299+)

### ❌ DESVENTAJAS DE ML:
1. **Costo fijo** de $25-$37 (mata productos baratos)
2. **Mayor competencia** (incluyendo chinos)
3. **Comisión más alta** en publicación Premium (20.5% máx)
4. **Menos valor percibido** de marca que Amazon

# 🔢 FÓRMULAS MÁGICAS PARA CÁLCULO RÁPIDO

## Mercado Libre:
```
Precio mínimo = (Costo + Costo fijo $37) ÷ (1 - 0.13 - 0.025)
Precio mínimo = (Costo + $37) ÷ 0.845

Para packs > $299:
Precio mínimo = Costo ÷ (1 - 0.13 - 0.025) = Costo ÷ 0.845
```

## Amazon:
```
Precio mínimo FBM = (Costo + $10) ÷ (1 - 0.15)
Precio mínimo FBM = (Costo + $10) ÷ 0.85

Precio mínimo FBA = (Costo + FBA fees) ÷ (1 - 0.15)
Precio mínimo FBA = (Costo + $25-60) ÷ 0.85
```
